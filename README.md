# دليل تشغيل موقع مكتب النجاح للاستقدام (Al Najah Recruitment Office)

موقع تعريفي وتفاعلي متكامل لمكتب النجاح للاستقدام، مبني بأحدث تقنيات الويب الأساسية (HTML5, Vanilla CSS3, JavaScript) بشكل متجاوب بالكامل وتصميم فاخر (Premium Navy & Gold).

تم تصميم الموقع بهيكل **الصفحات المتعددة (Multi-Page Architecture)** لتسهيل تصفح الأقسام بشكل مستقل.

---

## 📁 هيكل المجلدات (Project Directory Structure)

```
├── images/
│   └── logo.jpg          # الشعار الرسمي للمكتب
├── index.html            # الصفحة الرئيسية (الهيرو، الإحصائيات، آراء العملاء)

├── news.html             # صفحة الأخبار والعروض الترويجية
```

## 🚀 كيفية التشغيل والمعاينة المحلية (How to Preview Locally)

### الطريقة 1: الفتح المباشر
يمكنك تشغيل الموقع مباشرة عبر فتح ملف `index.html` في أي متصفح ويب (Chrome, Edge, Safari, Firefox).

### الطريقة 2: تشغيل سيرفر محلي (Local Dev Server)
للحصول على أفضل أداء للموقع وتفادي قيود المتصفحات لبعض الميزات المحلية، يمكنك استخدام إحدى الطرق التالية:

* **باستخدام Live Server (في VS Code):**
  انقر بزر الفأرة الأيمن على ملف `index.html` واختر **Open with Live Server**.
  
* **باستخدام Python:**
  افتح ترمينال في مجلد المشروع وشغّل الأمر التالي:
  ```bash
  python -m http.server 8000
  ```
  ثم افتح المتصفح واذهب إلى: `http://localhost:8000`

## 🛠️ تفاصيل التقنيات المستخدمة (Technical Details)

1. **Vanilla CSS3 Design System:**
   - استخدام متغيرات CSS (Variables) لتسهيل تغيير الألوان وتوحيد الهوية البصرية.
   - دعم التجاوب الكامل (Responsive Design) مع كافة قياسات الشاشات (الهواتف، الأجهزة اللوحية، الشاشات الكبيرة).
   - تأثيرات حركية خفيفة (Micro-animations) لتحسين تجربة المستخدم.

2. **JavaScript Interactivity:**
   - قائمة تنقل جانبية للجوال متكاملة وسلسة في جميع الصفحات.
   - أكورديون الأسئلة الشائعة في صفحة `faq.html` يغلق تلقائياً الأسئلة الأخرى عند فتح سؤال جديد.
   - نظام تصفية وبحث لحظي (Realtime Search & Filter) في صفحة السير الذاتية للتصفية حسب الجنسية، المهنة، الخبرة، أو الكلمات الدلالية بدون إعادة تحميل الصفحة.
